## Reading (written after the runs; basis: the same 6 JSON reports)

- Leaflet is off the first load: vendor-leaflet.js and vendor-leaflet.css were requested in 3 of 3 main runs and 0 of 3 branch runs.
- Script count 10 to 8 is TWO removals, only one of them this change: vendor-leaflet.js (44414 bytes transferred in main run 2) and
  static.cloudflareinsights.com/beacon.min.js (10478 bytes), the Cloudflare Web Analytics beacon, which the production custom domain
  injects and the *.pages.dev preview does not. So about 44 KB of the roughly 54 KB script drop is this change; the rest is the host.
- LCP: median 3245 ms on main and 2562 ms on the branch, ranges not overlapping (main 3223 to 3245, branch 2485 to 2711). Score median 85 to 89.
- TBT did NOT improve: main runs 87, 156, 222 ms; branch runs 195, 188, 452 ms (main-thread work 2.2 s vs 2.5 s in run 2). The cause is not
  established; the beacon's absence would lower branch TBT, not raise it. FCP is flat (995 vs 1048 ms) and Speed Index is equal (5338 ms).
- The clean measurement is a rerun on production after merge (same host, beacon on both sides).
